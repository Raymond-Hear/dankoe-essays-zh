# Dan Koe 长文集（中英对照）

Dan Koe 写了不少值得反复读的长文，但原文散在官网和邮件列表里，中文读者读起来有门槛。
这个仓库把它们整理成中英对照：每篇一个页面，中文译文和英文原文在同一页切换。

内容可以随意取用和改写。如果你想译新的、或者修订已有的某一篇，欢迎提 PR。

## 怎么用

- 在线阅读：打开 `index.html`（或部署后的地址）
- 只想拿译文：进 `content/`，每篇文章一个文件夹，中文和英文分开放
- 想加点自己的批注：直接改 HTML，或者 fork 一份随便改

## 目录

```
index.html      文章列表（搜索、按年份和主题筛选）
article.html    阅读页（中文译文 / 英文原文切换、目录、音视频来源）
about.html      关于本站与整理者
content/        文章正文
data/           文章目录与导读摘要
covers/         封面图
```

纯静态页面，没有后端，也不依赖构建工具。想本地跑得更接近线上环境：

```bash
python -m http.server 8000
```

## 收录范围

只收录 Dan Koe 公开发布的长文，付费内容不转载，只提供原站链接。
每篇文章都标了原文地址，需要核对措辞、数字或上下文时，请以原文为准。
